# Lernkonzept von Jappy

Zielgruppe: Menschen, die am besten durch **Hören, Sprechen und Ausprobieren** lernen – weniger durch Lesen.
Daraus folgt die Grundregel: **Klang vor Schrift, Tun vor Erklären.**

## 1. Der Lernzyklus jedes neuen Ausdrucks

1. **Hören** – Audio startet automatisch, Text erst danach (Input-Hypothese, Krashen).
2. **Verstehen** – Bedeutung, Beispielsatz, ggf. Eselsbrücke (duale Kodierung, Paivio).
3. **Nachsprechen** – Mikrofon mit Sofort-Feedback (Output-Hypothese, Swain).
4. **Abrufen** – Hörquiz ohne Text, dann Deutsch → Japanisch sprechen (Testing-Effekt, Roediger & Karpicke).
5. **Wiederholen** – automatisch kurz vor dem Vergessen (Ebbinghaus; SM-2-Algorithmus).

Max. 6 neue Ausdrücke pro Einheit (kognitive Belastung gering halten). Erst rezeptiv (Hörkarte), dann produktiv (Sprechkarte).

## 2. Methoden und ihre Umsetzung

| Methode | Quelle | Umsetzung in Jappy |
|---|---|---|
| Hören zuerst / verstehbarer Input | Krashen | „Erst hören, dann lesen“, Hörgeschichten auf drei Niveaus |
| Shadowing | Arguelles | Endlosschleife, Aufnahme + Vergleich, Aussprache-Check |
| Output-Hypothese | Swain | Mikrofon in fast jeder Übung |
| Aktives Abrufen | Roediger & Karpicke | Sprechkarten, Hörquiz, Rollenspiele ohne Vorlage |
| Verteilte Wiederholung | Ebbinghaus, SM-2 | 4-Stufen-Bewertung, individuelle Intervalle |
| Antizipation & gestaffelte Intervalle | Pimsleur | Audio-Lektion: Frage → Pause → Lösung, Wiederholung nach 2/5/10 Slots, Rückwärtsaufbau |
| Chunking / Lexical Approach | Lewis | Phrasen als Karteikarten, Dialogzeilen als Shadowing-Material |
| Aufgabenbasiertes Lernen | TBLT, Kolb | 16 Rollenspiele mit Kann-Zielen, Rollentausch |
| Entdeckendes Lernen | Bruner | Grammatik als Muster + Satzbau-Puzzle, Erklärung max. 3 Sätze |
| Duale Kodierung / Mnemotechnik | Paivio | Kana-Eselsbrücken (Form + Klang), Schreiben mit dem Finger |
| Phonologisches Training | Minimalpaare | Lange Vokale, Doppelkonsonanten, ん, stimmhaft/stimmlos |
| Interleaving | Bjork | Lernpfad wechselt Ausdrücke ↔ Anwendung |
| Adaptives Üben | Leitner | Kana-Quiz bevorzugt unsichere Zeichen |
| Gewohnheit & Motivation | Microlearning | Tagesziel, Serie, XP, kurze Einheiten |

## 3. Niveaus

| Niveau | Orientierung | Schwerpunkte |
|---|---|---|
| Einsteiger | ≈ JLPT N5 | Hiragana/Katakana, Überlebenssätze, です/ます, Partikeln |
| Grundstufe | ≈ JLPT N4 | て-Form, Erlaubnis, Vergleiche, Erfahrungen, einfache Form |
| Fortgeschritten | ≈ JLPT N3+ | Keigo, Konditionale, Passiv/Kausativ, Umgangssprache |

## 4. Feedback beim Sprechen

Die Spracherkennung liefert mehrere Varianten (Kanji/Kana). Jappy vergleicht alle mit der Kanji-Schreibweise, der
Kana-Lesung und akzeptierten Alternativen (normalisiert, Levenshtein-Ähnlichkeit):
≥ 85 % „Perfekt“, ≥ 60 % „Gut“, darunter „Nochmal“. Bei Sprechkarten schlägt das Ergebnis eine Bewertung vor.
